# Legal and Originality Checklist

Project codename: **Tower**

Status: Draft

This is not legal advice. It is a practical design checklist to reduce avoidable originality and copyright risks.

## Core Rule

The project may be inspired by genre conventions, but it must use original expression.

## Do Not Copy

- Existing game title, subtitle, logo, or branding.
- Existing character names, appearances, backstories, or silhouettes.
- Existing card names or exact card rules text.
- Existing relic names, icon concepts, or exact mechanics plus names.
- Existing event titles, event text, choice text, or outcomes presented in the same way.
- Existing enemy names, appearances, animation patterns, or distinctive mechanics.
- Existing UI assets, layout details, icon shapes, card frames, and visual treatment.
- Existing numerical balance tables.
- Existing sound effects, music, and voice assets.

## Safer to Reuse as Genre Conventions

These are broad genre/system ideas and can be implemented with original expression:

- Turn-based card combat.
- Energy or action points.
- Draw pile, hand, discard pile.
- Branching roguelike route maps.
- Normal combats, elites, events, shops, rest sites, bosses.
- Passive item/relic systems.
- Card upgrades.
- Status effects such as poison, weakness, vulnerability, or block-like defense.
- Permanent death per run with long-term unlocks.

## Originality Requirements

Before content is accepted, check:

- Does it have an original name?
- Does it have original art direction?
- Does it avoid copied text?
- Does it avoid recognizable character or item silhouettes?
- Does it use original numbers or altered mechanics?
- Does it fit this project's own world and theme?
- Can it be explained without referencing a specific existing card, relic, enemy, or event?
