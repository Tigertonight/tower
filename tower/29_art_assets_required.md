# Art / Audio Assets Required for Phase A1

Date created: 2026-05-11
Owner: solo dev (assets to be generated by the user, code wired by Claude as items are produced)
Scope: a *single, working* checklist for everything the Phase A1 demo slice needs. As Claude refactors code in A1.1–A1.9, any newly-introduced asset is appended here so the user can run the gen pipeline once.

Format:
- **ID** — used in code as the filename (without extension).
- **Path** — exact location the engine expects.
- **Type / size / format** — what to render.
- **Status** — `Missing`, `Placeholder` (a stand-in is wired so the game runs), `Done`.
- **Priority** — `P0` blocks gate G-A2; `P1` improves it; `P2` polish.
- **Notes** — visual prompt + any wiring caveats.

If you replace a placeholder asset, just save it to the listed path with the listed name; the code already references it.

## 9. How to use this checklist

When you sit down to generate:
1. Sort by Priority (P0 → P1 → P2).
2. Filter by Status (Missing → Placeholder → Done).
3. After saving an asset to the listed path, change Status to `Done` here.
4. If you decide to skip an asset for now, leave it as-is — the code already has a graceful fallback.

If a new asset is added during code work, it's Claude's job to append it here in the same format.
