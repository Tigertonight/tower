# Tower Project Docs

This folder stores the design, technical planning, project records, and asset-generation notes for the original roguelike deckbuilder project currently codenamed **Tower**.

## Document Index

- [01_game_design_research.md](./01_game_design_research.md): gameplay research and complete high-level design plan.
- [02_technical_design.md](./02_technical_design.md): Godot technical architecture, data model, runtime systems, and implementation plan.
- [03_project_log.md](./03_project_log.md): project progress, decisions, risks, and development diary.
- [04_asset_generation.md](./04_asset_generation.md): art direction, prompt notes, asset list, and generated material tracking.
- [05_content_database.md](./05_content_database.md): planned cards, relics, potions, enemies, events, and bosses.
- [06_legal_originality_checklist.md](./06_legal_originality_checklist.md): originality and copyright-risk checklist.
- [07_environment_setup.md](./07_environment_setup.md): local Godot development environment setup notes.
- [08_mvp_scope.md](./08_mvp_scope.md): locked MVP scope and non-goals.
- [09_first_character_design.md](./09_first_character_design.md): first playable character and starter content.
- [10_implementation_plan.md](./10_implementation_plan.md): first development sequence for the Godot project.
- [11_ui_reference_research.md](./11_ui_reference_research.md): UI reference research and interaction-pattern notes.

## Working Principle

The project may be inspired by the structure of roguelike deckbuilders, but it should use original characters, card names, relics, events, art direction, UI presentation, writing, and numerical content.
